## 前言
开发一个即时通讯系统，取名叫Owlsgo-Chat，也可以叫OChat。这是一个基于原生 PHP 8.1+ + SQLite、MySQL 和 PostgreSQL+ Workerman WebSocket 构建的现代化实时聊天室，无需框架依赖，开箱即用。采用自研扁平化 UI 设计（类名为ow开头），支持插件机制。适合web在线聊天、低成本部署和 AI 二次开发，完整适配移动端的系统。


## 特点

- 纯原生 PHP，单核心代码文件，无框架和 Composer 依赖，部署与维护简单
- 支持 SQLite、MySQL 和 PostgreSQL，数据库结构和搜索能力保持跨引擎兼容
- 支持用户角色、聊天室权限、站点设置、注册控制、发言限制和附件管理
- 插件机制支持 Hook、路由、后台页面、资源合并、在线安装更新和统一计划任务
- 站点设置、聊天附件和用户按需懒加载，数据库结构简单，负载能力强
- 支持 AJAX 交互和响应式布局，兼顾 PC 与移动端使用体验


## 功能介绍：

### 聊天核心

- **多聊天室** — 支持创建公开、私密（密码）、限定角色三种类型的聊天室 
- **实时消息** — WebSocket 实时推送，心跳保活，断线自动降级轮询 
- **消息类型** — 普通消息、@ 提及（全员可见）、私信（仅双方可见）、系统消息 
- **消息撤回** — 发送者 3 分钟内可撤回，管理员与房主可撤回任意消息 
- **历史消息** — 滚动到顶部自动加载更早消息，无限翻页 
- **图片消息** — 支持上传图片、粘贴发送，点击大图预览 
- **自定义表情** — 内置 Emoji 面板 + 用户可上传收藏贴纸表情 
- **消息提示音** — 新消息到达时播放提示音 

### 用户系统

- **独立注册登录** — 用户名 + 邮箱注册 1
- **邮箱验证码校验** 4
- **密码找回** — 通过邮箱验证码重置密码 5
- **游客模式** — 可配置是否允许游客浏览 / 发言，游客自动分配随机昵称 2
- **游客限额** — 游客每日发言数量限制，可在配置中调整 3
- **个人资料** — 点击用户名弹出资料卡，支持修改昵称、上传头像 2
- **身份角色** — 管理员、VIP、普通成员、游客，各角色显示不同颜色标签 2
- **用户称号** — 管理员可为用户设置自定义称号 3

### 在线状态

- **实时在线列表** — 右侧栏显示当前房间在线成员，圆形头像 + 身份标签 3
- **WebSocket 心跳同步** — 精确的在线 / 离线状态追踪 2
- **IP 归属地** — 管理员可查看用户 IP 归属地（通过 ip-api.com）2

### 管理后台 2

- **用户管理** — 搜索用户、修改角色、设置称号 2
- **禁言系统** — 支持按用户 / 游客昵称 / IP 禁言，可按房间隔离，支持设置过期时间3
- **敏感词过滤** — 后台添加敏感词及替换词，支持启用 / 停用 3
- **聊天室管理** — 创建 / 编辑 / 删除聊天室，设置访问权限和发言权限 2
- **房主机制** — 可指定聊天室房主，房主拥有该房间的消息撤回权限 2
- **公告系统** — 支持创建公告和欢迎消息，可绑定到指定聊天室，支持优先级排序和轮播展示 2
- **安全日志** — 记录登录、注册等关键操作的 IP 和请求数据 2

### 安全机制

API 签名验证 — 前后端通信使用签名，密钥混淆传输
频率限制 — 基于 Redis 的消息发送频率限制
登录保护 — 连续失败后触发验证码，超过阈值自动锁定
邮件频率限制— 防止邮件接口被滥用
